# Gitea MCP Server

Lets Assist, Claude and ChatGPT work with your own Gitea: search repositories, read files, and
look at or write issues and pull requests.

* Finds the Gitea app by itself. You only enter an access token.
* Read-only by default, with a choice of tool groups.
* Optional remote access for claude.ai and ChatGPT, with a guided setup on the app page.

> **Pre-release.** This is a `dev` version. Please report what you see.

Open the *Documentation* tab for setup, remote access and troubleshooting.
